- **核心气质**：高端运动会员 App，不是账本工具、也不是糖果养成；关键词是黑白基底、强数字、少量荧光收益反馈。
- **产品隐喻**：首页像“高级会员卡包”，卡片是主角；打卡不是记账动作，而是一次“使用确认 + 单次成本下降”的即时反馈。
- **视觉目标**：清醒、省钱、掌控感。避免可爱贴纸、廉价渐变、脏糖果色、概念稿式口号。

**颜色系统**
- 主色板在 `worthit-ios-home.html:8`。
- **背景**：冷白 / 浅灰，负责干净和高级感。
- **前景**：炭黑 / 深墨色，承载主卡和核心数字。
- **点睛色**：荧光绿，只用于“收益、下降、确认使用”等正反馈。
- **状态色**：黄色用于提醒，红色用于风险，青绿色作为辅助信息色。
- **使用原则**：绿色不能做大面积装饰，只能服务于“这次使用让成本下降”这一件事。

**排版系统**
- **Display**：`DIN Condensed / Arial Narrow / SF Pro Display`，用于大数字和强标题，制造运动会员感。
- **Body**：`SF Pro Text / PingFang SC`，用于产品文案和列表信息。
- **Mono**：`SF Mono / DIN Alternate`，用于金额、次数、成本等数字信息。
- **层级原则**：大数字优先于说明文字；用户第一眼应看到“当前单次成本”和“使用后能降到多少”。

**组件语言**
- **主卡**：`worthit-ios-home.html:291`，黑色会员卡质感，是首页视觉中心；不再使用右侧大色块或突兀荧光点。
- **钱包队列**：`worthit-ios-home.html:334`，显示除当前主卡外的候选卡，承担“卡包堆叠”而不是纯装饰。
- **确认按钮**：`worthit-ios-home.html:504`，主行动按钮，荧光绿是最强反馈点。
- **卡包列表**：`worthit-ios-home.html:690`，真实产品信息卡，支持选中态、筛选、空态。
- **底部导航 / 抽屉**：保持 iOS bottom sheet 和 Tab 的真实 App 结构，不做展示页控件。

**交互原则**
- 点击任意卡片后，它会成为顶部主卡；打卡只作用于当前选中卡。
- 点击“确认使用一次”后，更新已用次数、连续次数、当前单次、使用后单次，并给数字短促反馈。
- 筛选分类时，如果当前卡不在分类内，会自动切到该分类第一张卡，避免主卡和列表脱节。
- 动效只用 `transform` / `opacity`，并保留 `prefers-reduced-motion` 兜底。

**后续延展规则**
- 新页面也应沿用“黑白会员卡 + 强数字 + 小面积荧光反馈”。
- 卡片详情页应强化历史使用、成本曲线、风险提醒。
- 打卡确认页可以更有仪式感，但不要做金币、抽奖、贴纸等廉价游戏化。
- 文案要像真实产品：少讲理念，多讲“今天该用哪张、这次能降多少、哪张快闲置”。

核心公式

预计总次数 N = F × 52 × Y
净投入 C0 = P + M×Y − R
单次成本 C = C0 ÷ N
回本次数 K = P ÷ T
年化成本 = C0 ÷ Y · 月均 = 年化 ÷ 12
P价格（必填，> 0）F每周使用次数（0.1–21）
Y使用年限（0.25–10）T单次心理价位（默认 ¥30）
M年维护成本（选填，默认 0）R残值抵扣（选填，默认 0，≤ P）

评分权重（0–100）

成本 60% 频率 25% 规模 15%

成本分：C ≤ 0.5T 记 100 分，C ≥ 1.5T 记 0 分，中间线性。频率分：F ≥ 3 记 100，0.1 记 0，中间线性。规模分：N ≥ 150 记 100，N ≤ 10 记 0，中间线性。总分 = 0.6×成本 + 0.25×频率 + 0.15×规模，四舍五入取整。展示值四舍五入（金额 2 位小数），计算始终用精确值。

结论级联（按顺序判定）

  1. 1
    输入不合法 — 阻止计算，逐字段提示，不写入台账。
  2. 2
    K > N — 预期使用次数内回不了本 → 不建议。
  3. 3
    评分 < 40 或 C > 1.1T — 成本明显超出心理价 → 不建议。
  4. 4
    （C ≤ 0.7T 且评分 ≥ 60）或（评分 ≥ 75 且 C ≤ T） — 值得买。
  5. 5
    其余 — 边际情况：贴着心理价，成败看使用坚持度。
